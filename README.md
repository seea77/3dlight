# 3D 商品布光实验室

浏览器端的摄影布光教学工具，面向电商 / 短视频拍摄课程。基于 Three.js 构建，无需安装、无需联网，直接用浏览器打开即可使用。

## 功能模块

| 文件 | 说明 |
| --- | --- |
| `index.html` | 主工作室：3 灯布光模拟 + 已合并的相机参数练习页。默认首屏为相机练习，可一键进入 3D 布光。 |
| `index-wide.html` | 大屏（宽屏）版工作室，右侧栏布局，适合投影 / 教室大屏演示。 |
| `index-desktop.html` | 桌面版工作室，面向鼠标操作的 PC 端界面。 |
| `camera.html` | 相机模拟：原生 WebGL 实现，演示快门、光圈、感光度等参数对成像的影响。 |
| `单反相机3D结构展示.html` | 单反 / 微单相机 3D 结构解剖，可旋转查看内部构造。 |
| `scene-trainer.html` | 3D 拍摄场景训练：可调节背景、道具小球、取景框与构图辅助线。 |

## 技术要点

- 渲染：Three.js r169（已内联进 HTML，无 CDN 依赖），`camera.html` 为原生 WebGL。
- 阴影：PCSS 接触硬化阴影（Contact Hardening Shadows），模拟真实柔光箱的近硬远软过渡。
- 交付形态：单文件 HTML，所有代码 / 样式 / 模型数据内联，整目录即为一个完整应用。
- 各页面相互独立，可单独打开，也可整体部署。

## 运行方式

- 本地预览：直接用浏览器打开 `index.html`（双击即可，无需服务器）。
- 静态托管：将整个目录上传到任意静态托管服务即可，例如 GitHub Pages、WorkBuddy 应用托管等。入口为 `index.html`。
